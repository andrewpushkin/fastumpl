UML class diagrams that lay themselves out.

fastumpl is a native desktop editor for UML class diagrams. Draw or type your classes; it places the boxes and routes every line around them, keeping crossings to a minimum.

Windows macOS Linux .deb All downloads

Free and open source (MIT). Written in Rust.

Why fastumpl

Tidy in one key

Press Ctrl+T and the whole diagram is laid out: parents above children, related classes side by side, no overlapping boxes, no lines through boxes.

Few crossings

Crossings are removed at five stages, from box order to line routing, and several candidate layouts compete. The status bar shows the crossing count, so you can see when a tidy would help.

Lines follow you

Drag a class and its lines reroute as you move. Auto layout never undoes your own placement unless you ask it to.

Type, don't click

Double-click a class and type its members as text: +total(): Money. The same syntax as the file.

Files that diff well

Diagrams are plain text. The model sits at the top, positions at the bottom, so a code review shows whether a change was to the design or only to the picture.

Fast and native

A small native app that starts instantly and stays smooth on diagrams with hundreds of classes. A command-line tool renders SVG and PNG for docs and CI.

The .umpl file

A small text format close to PlantUML class syntax. Write it by hand, generate it, or let the editor write it for you. Elements without a position are placed automatically when the file opens.

  • --|> extends, ..|> implements
  • *-- composition, o-- aggregation
  • -- association, --> directed, ..> dependency
  • "1..*" multiplicities and role names at each end
  • Packages, notes, stereotypes, comments
diagram "Shop"

package billing {
  abstract class Payment {
    +amount: Money
    +pay(): Receipt {abstract}
  }
  class CardPayment
}

class Order {
  +id: OrderId
  -lines: List<OrderLine>
  +total(): Money
}

# an order owns its lines
Order "1" *-- "1..*" OrderLine : contains
billing.CardPayment --|> billing.Payment
Order --> billing.Payment : paid by

layout {
  Order           at 24, 8
  billing.Payment at 48, 8
}
